# Codex Review — 2026-06-23T00:15:26Z

## Scope

Review of `dir3_manifold`, focused on whether the implementation is correct and
whether the interpretation in `RESULTS.md` / `REPORT.md` is faithful.

## Overall Verdict

The implementation looks broadly reasonable for a pilot study. The project now has
the right kinds of controls: PCA, TwoNN/MLE, synthetic validation, standardized
checks, position buckets, longer AE training, and a parameter-matched AE sweep.

The interpretation is much more faithful than earlier drafts. The defensible
conclusion is:

> Layer-6 GPT-2 small activations on this FineWeb sample have low estimated local
> intrinsic dimension, around 11-13 by TwoNN/MLE. AE sweeps are consistent with a
> low-k bend on raw activations, but are not independent proof of a manifold
> dimension because the knee vanishes under standardization and there is no true
> plateau.

## Findings

1. **AE interpretation is still slightly too positive.**

   `RESULTS.md` says the parameter-matched AE removes the parameter-count objection
   and that the knee survives. That is useful, but the same section admits the
   curve still has no plateau and the standardized AE knee vanishes. The AE should
   remain "a raw-variance reconstruction artifact consistent with low ID," not
   strong corroboration.

2. **The parameter-matched AE does not vary only the bottleneck.**

   The matched architecture changes `h1` from 576 at `k=2` to 512 at `k=256` to
   keep total parameter count fixed. That controls parameter count, but it also
   changes non-bottleneck architecture capacity. The statement that `k` is the
   "only varying information channel" is not quite faithful. Better wording:

   > Parameter count is held approximately fixed by trading outer hidden width
   > against bottleneck width.

3. **The matched AE table appears incomplete or inconsistently reported.**

   In the matched AE table, `train_FVU` is missing for `k=128` and `k=256`. If the
   run completed, these values should be filled in. If it did not, the section
   should say the matched sweep is partial. This matters because high-k behavior is
   part of the "no plateau" claim.

4. **The local-ID implementation is plausible, but fragile around duplicates.**

   The inspected `id_estimate.py` implementation uses kNN distances and drops the
   first nearest neighbor as self. If exact duplicate activation vectors occur,
   especially after fp16 storage, additional zero-distance neighbors can leak into
   TwoNN/MLE. TwoNN filters `r1 == 0`, but MLE floors zero distances to `1e-12`,
   which can bias estimates. This probably does not dominate, but a robust
   implementation should explicitly mask self by index and report duplicate counts.

5. **Final-layer interpretation may be risky.**

   The collection code uses HuggingFace `GPT2Model(..., output_hidden_states=True)`
   and indexes `hidden_states[L+1]`. For GPT-2, the last returned hidden state may
   be post-final-layernorm rather than raw block-11 `resid_post`, depending on the
   Transformers version. Layer 6 is likely fine; layer 11 is the risky one. Since
   most conclusions focus on layer 6, this is not fatal, but layer-11 claims should
   be treated cautiously.

6. **"Stable across token position" is still too smooth as headline wording.**

   The detailed section correctly notes that MLE varies across buckets, while TwoNN
   is stable. The headline should avoid saying simply "stable across token
   position." Better:

   > Low across coarse position buckets; TwoNN is stable, MLE shows
   > estimator-dependent variation.

## What Looks Correct

- PCA and variance-spectrum reporting look appropriate for a first pass.
- TwoNN/MLE estimates are reported with important caveats.
- Synthetic validation now exists and is correctly scoped in the current writeup.
- The AE result is no longer presented as proof of a manifold dimension.
- Standardized-AE failure is correctly treated as a major caveat.
- Parameter matching is a useful added control, even though it changes architecture
  width.

## Interpretation Fidelity

Faithful:

- "Low local ID at layer 6 on this sample" is supported as a pilot result.
- "AE is weak / preprocessing-sensitive" is supported.
- "Not demonstrated globally" is the right caveat.

Still too strong:

- "Stable across token position" without qualifier.
- "Bottleneck k is the only varying information channel" in the matched AE.
- Any wording implying the AE bend independently confirms the manifold dimension.

## Recommended Next Steps

2. Rephrase the matched-AE section to acknowledge that `h1` varies.
3. Re-run ID with explicit diagonal/self masking and duplicate-distance diagnostics.
4. Verify exactly what `hidden_states[L+1]` means for layer 11 in the installed

5. Add bootstrap confidence intervals for layer-6 TwoNN/MLE.

7. Keep the final claim scoped to layer 6, this model, and this FineWeb sample.
