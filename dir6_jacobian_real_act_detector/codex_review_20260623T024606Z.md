# Codex Review - 20260623T024606Z

Scope: reviewed Direction 6 implementation and writeup for correctness and faithfulness.

## Findings

1. **Phase 5/6 "in-context" downstream KL is not actually in-context.**

   In `experiments/context_validation.py`, `continue_from()` wraps the activation as `[B, 1, 768]` and runs only that single position through later GPT-2 blocks. That drops previous-token hidden states, so later-layer attention cannot attend to the prompt context. The same pattern appears in `experiments/causal_repair.py`.

   This makes the explanation in `REPORT.md` and `RESULTS.md` too strong where it says these phases measure "true in-context KL(clean||corrupt)". The implementation measures single-token continuation from a layer-6 residual vector, not full-context continuation.

2. **The causal repair "matched random move" comparison is not matched for `func_descent`.**

   `experiments/causal_repair.py` defines the control move budget from `rep_maha`, and all controls use that budget. `budget_f` is computed but never used. The result JSON shows `func_descent` moved `83.57`, while `random_move` moved `78.26`.

   Therefore the claim that functional descent is worse than a "matched-distance random move" is not strictly supported. It is worse than the shown random control, but not at exactly equal move budget.

3. **Combined LOFO AUROC leaks held-out label orientation.**

   In `experiments/combined_score.py`, the learned logistic score is evaluated on the held-out family and then reported as `max(au, 1 - au)`. For a trained detector, score orientation should be fixed by the training labels. Flipping using held-out labels is fine for diagnostic single-feature probes, but not for a generalization claim about a learned detector.

   This weakens the claim that the combined detector generalizes to covariance-matched Gaussian at AUROC 0.999.

4. **The single-position functional probe is represented mostly honestly, but one phrase is overclaimed.**

   `experiments/functional_features.py` also feeds `[B, 1, 768]` through later blocks. The report discloses this limitation, which is good. However, "verified to reconstruct true logits exactly when given full context" is not evidenced by the checked script, and the benchmark itself does not use full context.

5. **The activation split claim is plausible but not fully auditable.**

   Direction 3 collection appends all non-padding token activations in document order, so a contiguous split plus 5k-row gap is probably a reasonable leakage reduction. But no per-row document metadata is stored, so "document-leakage control" should be phrased as "contiguous split with gap to reduce leakage," not a verified document-level split.

## What Looks Faithful

The statistical benchmark story is mostly faithful:

- kNN and Mahalanobis complementarity is supported.
- Norm shortcut limitations are supported.
- The interpolation correction from one-sided to two-sided Mahalanobis is supported.
- Learned raw-activation detector LOFO failure is supported.

## Bottom Line

Claims 1-2 are fairly solid for the constructed benchmark. Claims 3-4 should be downgraded because the "downstream/in-context" validation is actually single-position late-block continuation, and the functional causal comparison is not exactly move-matched.
